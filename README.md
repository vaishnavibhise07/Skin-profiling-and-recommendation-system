# Skin-profiling-and-recommendation-system
A machine learning-based system that analyzes facial images to detect skin tone, type, and acne, and recommends skincare and cosmetic products accordingly.
## Personalized Skincare and Makeup Recommendation System

This web application provides personalized skincare and makeup recommendations based on facial skin characteristics extracted from a user's selfie. It combines Computer Vision and Deep Learning techniques to identify three key attributes:

- **Skin Tone**
- **Skin Type**
- **Acne Severity**

Using these attributes, the system identifies suitable products through cosine similarity, ranking recommendations according to how closely they match the user's skin profile.

### Working Process

**1. Image Capture and Face Validation**

Users capture a selfie using their webcam. Real-time face detection checks that:
- Only one face is present in the frame.
- Lighting conditions are sufficient.
- The face is clearly visible and occupies an appropriate portion of the frame.

Once the image passes these checks, the user proceeds to the next stage.

**2. Skin Information Confirmation**

The application displays a form containing the skin characteristics predicted from the captured image. Users can review the extracted information, make corrections, or specify additional skin concerns before submitting the form.

**3. Product Recommendations**

The system displays the most relevant skincare and makeup products in a card-based layout. Recommendations are generated by comparing the user's skin profile with product attributes stored in the dataset.

### Model Architecture

**1. Skin Tone Classification**

Skin pixels are identified using thresholding and color-space filtering techniques in HSV and YCrCb color spaces. A K-Nearest Neighbors (KNN) model then classifies the average extracted skin color according to the Fitzpatrick skin tone scale.

**2. Skin Type and Acne Severity Prediction**

Two separate Convolutional Neural Network (CNN) models are used to analyze skin characteristics:

- **Skin Type Model:** Classifies skin as Dry, Oily, or Normal.
- **Acne Severity Model:** Categorizes acne concerns into Low, Moderate, or Severe.

Both models leverage EfficientNetB0 through transfer learning to extract relevant image features and perform classification.

**3. Product Recommendation Engine**

Each product in the dataset is associated with relevant skin types, skin tones, and skin concerns. The system compares these attributes with the user's skin profile using cosine similarity and ranks the products based on their relevance. Recommendations are presented across different product categories.

### Key Features and Outcomes

- Personalized skincare and makeup recommendations based on facial skin analysis.
- Real-time webcam capture with face visibility and lighting validation.
- Automated skin tone, skin type, and acne severity classification.
- An interactive interface for reviewing and updating detected skin information.
- A cosine similarity-based recommendation engine for matching products to individual skin profiles.
- A backend pipeline that processes images, predicts skin characteristics, and generates relevant product suggestions.

### Project Background

The project draws inspiration from publicly available research papers, open-source implementations, and established techniques in Computer Vision and Deep Learning. These concepts were adapted and integrated to develop a personalized product recommendation platform based on facial skin analysis.
